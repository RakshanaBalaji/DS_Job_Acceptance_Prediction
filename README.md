# DS Job Acceptance Prediction System

## 📌 Project Overview
This project predicts whether a candidate will accept a job offer using Machine Learning.

## 🎯 Objective
To help companies identify candidates who are likely to change jobs.

## 📊 Dataset
HR Analytics Job Change Dataset

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🔍 Steps Performed
1. Data Cleaning
2. Exploratory Data Analysis (EDA)
3. Feature Engineering
4. Model Building
4. Model Evaluation

## 🤖 Models Used
- Logistic Regression
- Random Forest

## 📈 Results
Random Forest performed better than Logistic Regression.

## 📊 Key Insights
- Mid-level experienced candidates change jobs more
- Training hours influence job change
- Company size impacts decisions
